## Aula 01.1



Mongo DB: É um banco de dados NoSQL orientado a documentos, o que significa que ele armazena dados em formato semelhante ao JSON.



Express: Simplifica o desenvolvimento de servidores e manipulação de rotas, com uma sintaxe clara e intuitiva.



React: É uma biblioteca JavaScript desenvolvida pelo Facebook para construir interfaces de usuário (UIs) interativas e reutilizáveis.

&nbsp;  Facilita a criação de componentes de UI que podem ser reutilizados em diferentes partes da aplicação, melhorando a manutenção do código.

&nbsp;  Performance eficiente através do Virtual DOM, uma comunidade ativa, e um grande ecossistema de ferramentas e bibliotecas.



Node Js: É um ambiente de execução JavaScript no servidor, baseado no motor V8 do Google Chrome.

&nbsp;  Permite a construção de alta performance e escaláveis, com um modelo de I/O não bloquente.

&nbsp;  Utilização de JavaScript em todo o stack, grande quantidade módulos disponíveis através do NPM, e adequação para aplicações em tempo real.
